# Simulador do Problema da Correspondência de Post (PCP)

Este projeto é um simulador em Python para o **Problema da Correspondência de Post (PCP)**, desenvolvido para a disciplina de **Teoria da Computação** (Engenharia).

## 📚 Referência Bibliográfica
- **Diverio, T. A.; Menezes, P. B.** *Teoria da Computação: Máquinas Universais e Computabilidade*. Cap. 9 - Computabilidade.

## 🎯 Sobre o PCP
O Problema da Correspondência de Post é um problema de decisão indecidível introduzido por Emil Post em 1946. Dada uma coleção de peças com cadeias de caracteres na parte superior e inferior, o objetivo é encontrar uma sequência de peças onde a concatenação da parte superior seja idêntica à concatenação da parte inferior.
